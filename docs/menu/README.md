# The menu

`golden-gate-menu.docx` is the card I wrote for The Golden Gate: ninety two dishes across
seven sections, with their descriptions and prices. It is original work. The dishes, the
wording and the prices are mine, set at Lagos fine-dining level, and it is not drawn from
any existing restaurant.

It is the source `prisma/seed.mts` was written from, so the document and the database
agree. The preparation times are not in it: I set those separately, dish by dish, because
the brief requires one on every item and computes the promised wait from it. The bands are
in the submission document.

It sat in `docs/assignment/` for a while, next to the brief and the engineered model. That
was misleading: it made my own menu look like something the assignment supplied, which is
the opposite of true. It lives here instead.
