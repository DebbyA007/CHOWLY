# Photography

Every photograph in CHOWLY is served from this repository under `public/photos/`, because
the app's Content Security Policy allows images from its own origin only. Each one was
downloaded from the source below, cropped square and centre-weighted (the room to
390 by 452 at two times), resized, and re-encoded as JPEG. One CSS treatment sits over
all of them so eleven sources read as one shoot: a touch warmer and a touch darker
(`sepia(0.18) saturate(1.05) contrast(1.05) brightness(0.9)`). No other edits.

cropped files themselves, which stay under the same licence as their sources.
